탐색 성능을 높이기 위해 균형 있게 높이를 유지하는 Balanced Tree의 일종.
이진 트리가 아닌 다분기 검색 트리이다.
내부 노드의 Key가 k개 이면 자식 포인터는 최대 k+1개.
모든 Leaf Node가 같은 Level로 유지되도록 자동으로 밸런스를 맞춰준다.

### B-Tree의 시간 복잡도와 DB 사용 이유
탐색, 삽입, 삭제 : O (log N)
노드 하나에 많은 Key를 저장해서 Tree의 Level을 낮춤
디스크 / 메모리 페이지 단위 I/O를 줄이기 위해서 인덱스에서 사용하나, [[B+Tree]]를 더 많이 사용함.
