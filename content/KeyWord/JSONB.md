JSONB 같은 경우는 JSON-Binary 의 약자로 기존의 데이터 포맷 값을 바이너리 포맷으로 저장을 하는 것이다.

JSON  VS JSONB

둘의 공통점은
JSON 포맷 유효성 체크를 한다는 것.

둘의 차이점은
JSONB는 JSON에 비해서 저장 할 때 텍스트 그대로 저장하지 않는다. 앞뒤 공백을 제거 하고 저장.
Key 순서도 보장 하지 않고 저장한다.

따라서 JSON은 [[인덱스]] 저장이 되지 않아 인덱싱이 되지 않는다.
JSON은 [[인덱스]]적용이 되기 때문에 읽기 작업에 유용함. insert 쓰기 작업은 느리지만..

그리고 집계 함수 쿼리 aggregate query 같은 경우는 JSON 쿼리보다 조금 느리다고 함.
