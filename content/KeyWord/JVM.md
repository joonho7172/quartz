Java virtual machine의 약자.
java virtual machine jvm은 java로 개발한 프로그램을 컴파일하여 만들어지는 바이트코드를 실행시키기 위한 가상머신이다. 

[[JRE]] 에 포함이 되어 있음. 

JVM은 총 3개의 부분으로 구성이 되어 있으며,

1. 클래스 로더
2. 실행 엔진
3. 런타임 데이터 영역
4. JNI
5. Native method library로 구성이 되어 있다.
