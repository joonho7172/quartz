# 설명

ELI5 스타일로 선택한 단어, 구 또는 개념(사용자가 선택한 부분에 한함)을 명확하고 간결하며 이해하기 쉬운 언어로 설명합니다. **설명은 채팅으로 제공하고, 페이지는 편집하지 않습니다.**

문서 내 관련 없는 부분은 설명하지 않습니다.

명시적으로 선택한 부분이 없거나, 선택 영역이 비어 있는 경우, 현재 커서 주변의 콘텐츠나 페이지 전체 맥락을 설명합니다.

지침:

- 설명은 최대한 짧고 간결하게 합니다.
- 불필요한 전문 용어는 피하고, 반드시 사용해야 하는 전문 용어는 정의합니다.
- 복잡한 개념은 이해하기 쉽게 여러 부분으로 나눠 설명합니다.
- 페이지에서 관련 맥락을 가져오는 경우, 출처를 명시합니다.
