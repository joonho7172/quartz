단순 캐시가 아니라 세션의 저장소를 MongoDB에서 Redis로 바꾸는 작업. 
로그인·로그아웃·세션 만료·단일 세션 정책은 유지하면서, 메시지마다 발생하던 Mongo 세션 조회·갱신을 Redis TTL 갱신으로 대체.

현재 세션 저장소와 Redis 설정을 다시 확인한 뒤, 기존 Mongo 세션도 첫 요청 시 만료 시간을 유지한 채 Redis로 옮기도록 구현. 
그래서 배포 직후 사용자가 전부 강제 로그아웃되지는 않게 처리

메시지마다 세션 조회·갱신이 MongoDB에 두 번까지 갈 수 있는데, 이를 Redis 키(`session:v1:{userId}`)의 TTL 갱신으로 바꿉니다. 기존 Mongo 세션은 Redis에 없을 때 한 번만 옮긴 후 삭제해서, 전환 중에도 세션 만료 시간과 단일 로그인 정책을 유지합니다.
