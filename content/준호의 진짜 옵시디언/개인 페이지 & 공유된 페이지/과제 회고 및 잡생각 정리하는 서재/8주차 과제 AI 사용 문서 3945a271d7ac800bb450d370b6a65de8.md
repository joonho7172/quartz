# 8주차 과제 AI 사용 문서

# 1. jwt 구현의 큰 흐름이 어떻게 되냐고 물어봄

- 로그인 성공시 jwt 발급, 프론트가 jwt 저장, 매요청마다 헤더에 jwt 포함, 백엔드의 jwt 필터에서 토큰 검증, 결국은 컨트롤러에서 userId를 쿼리로 받는 것 보다 Security Context에서 꺼내기.

# 2. RequiredArgsConstructor 와 autowired의 차이

- 블로그 몇 개 뒤져보다가 다들 그냥 정확한 이유는 안알려주고 그렇다더라 고만 해서 ai에게도 차이와 장단점 답변 받고 회고에 정리해놨습니다.

# 3. API 응답 내려서 실패 한 API 찾기

- 코드 수정 할 때마다 하나하나 postman으로 응답 보내서 오류 찾는게 비효율적인거 같다고 생각해 오류가 있는 api 부분만 요청 받았습니다.

# 4. test코드 작성

- 테스트 할 실패 조건들을 먼저 구상해서 입력하고 성공 응답 코드를 요구 했습니다.
- signup을 예시로, 중복 이메일, 중복 닉네임의 실패 그리고 성공시 반환 값을 제대로 돌려주는지에 대한 테스트 코드를 요구하고 비밀번호 요구 조건은 따로 dto 단계 검증에서 테스트 할 것을 요구했습니다.
