# 1일차 배운 것

**개발자 의식?이 좀 중요하다 경험이 중요하다는 것임**

jdk 는 그 자체의 자바가 아니라

자바의 언어로 프로그래밍 된 코드를 실제 프로그램으로 묶기 위한 도구임 (스타터팩 같은 느낌)

자바(글)을 쓴다고 책 출판은 x

Jdk -> 실행 도구 jve->실행 환경

한번 설치하고 끝나는게 아니라 빌드, 배포 운영까지 같이 간다

즉, java	개발하기 위한 도구 모음이고

그 안에 컴파일러, 실행, 문서화, 패키징 도구 다양한 도구들이 있어

JRE는 실행환경, JVM은 바이트 코드 실행하는 가상 머신임

Java Run Environment

Java Virtual Machine  이 차이인듯?

개발할때는 jdk 가 필요하지만 배포할때는 딱히 필요없는듯? 개발자 도구 포함 차이기 때문

- JVM*

사용 이유 :

1. 중간계층이 생기면서 운영체제에 관계없이 동일하게 동작할 수 있게 해줌 ***
2. 네이티브 코드로 최적화 해줌 (jit 컴파일)
3. 클래스 코딩을 관리 해줌
4. 메모리 구조를 제공함.
5. GC를 통해 직접 참조되지 않는 객체를 자동으로 정리
6. 실행 최적화와 안정성 기능을 제공

실제 성능 튜닝 사례로도 이용됨

java 소스 코드는 바로 실행이 되는 것이 아닌 .class 바이트 코드로 컴파일이 된 이후로 jvm에서 실행이 되는 것 임

- 이 코드는 jvm안에서 어떤 흐름으로 흘러가는 가를 중요하게 알아야됨

java전용 실행기는 아님 다른 kotlin이나 sclala등 다른 jvm이 이해할 수 있는 언어로 되어있는 것들도 컴파일 가능

- JVM은 어떤 걸 실행 하는 가
    - Java 소스코드는 사람이 읽기 좋은 코드 , main 이나 static public 정도
    - javac컴파일러가 이 소스코드를 .class 파일로 바꿔줌 이거는 운영체제가 직접 실행하는 것이 아닌 jvm이 실행하는 바이트 코드.
