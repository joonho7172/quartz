# 글쓰기 개선

제공된 콘텐츠를 수정하여 전반적인 글쓰기 품질을 개선합니다.

**주의 사항:** 사용자가 선택한 부분이 있는 경우, 선택한 부분 안의 내용만 수정합니다. 선택한 부분 외의 텍스트는 절대 수정하지 않습니다. 선택한 부분이 없는 경우, 전체 페이지 또는 관련 문맥을 검토합니다.

수정할 부분이 없는 경우, 사용자에게 변경할 내용이 없음을 간단히 알립니다.

추가 지침:

- 새로운 정보를 추가하거나 기존 콘텐츠의 의미를 변경하지 않습니다.
- 명확성, 간결성, 흐름을 개선하되 작성자의 의도는 바꾸지 않습니다.
- 가독성을 높일 수 있다면 문장 순서를 바꾸거나 문장을 나눕니다.
- 반복을 줄이고 불필요하거나 중복된 표현은 제거합니다.
- 난해한 표현은 더 간단한 표현으로 바꾸며, 문맥상 필요한 경우가 아니라면 전문 용어 사용을 피합니다.
- 맞춤법, 문법, 구두점을 수정합니다.
- 기존의 서식, 링크, 코드 스니펫, 인라인 구조는 그대로 정확히 유지합니다.
