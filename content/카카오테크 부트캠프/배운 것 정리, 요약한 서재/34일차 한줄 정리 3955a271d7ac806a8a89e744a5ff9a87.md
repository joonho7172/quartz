# 34일차 한줄 정리

This, 클로저, JSX, 프로토타입, react

this는 다른 변수들과는 다르게 선언 위치보다는 호출위치에 의존적이다.

this의 호출 방식에는 여러 가지가 있는데.. bind 호출이 함수를 바로 실행하지 않는다는 예외가 있음. 

생성자 함수를 호출 할 때는 new를 꼭 해줄것, 안해주면 기본 호출이 되어서 undefiend가 될 수도 있다..

그리고 화살표 함수로의 호출은 자기 자신만의 this를 만들지 않고 선언된 스코프 바깥의 this를 호출한다는 유읮점이 있다.. 

스코프는 함수가 자기 자신이 선언된 위치를 기억한다는 성질인데, 함수를 반환하는 과정에서 쉽게 볼 수 있다. inner()함수가 다른 곳에서 콜백되거나 반환이 되었을 때, 내부 변수에 접근 할 수 있던 이유도 클로저 때문..

주로 함수 내부의 변수를 안전하게 보호하기 위해서 사용함.. 약간 캡슐화랑 비슷한 기능을 수행하기 위한 도구

그리고 내부 변수에 접근할 때는 값 복사가 아닌 참조이다.

프로토 타입은 공통 된 기능을 묶어 놓은 기능. 매번 객체를 새로 만들면 생성 비용이 너무 커지니 공통된 기능을 연결하자는 취지, 순서는 내부 메서드에서 프로토 타입 메서드로 체인을 따라 올라감

주요 토대가 클래스이고 예시는 list의 length나 includes..

react는 컴포넌트 단위로 UI를 선언적으로 간단하게 구성하기 위해서 사용

JSX는 UI구조와 그 안에 데이터를 한곳에서 보기 위해서 사용한다..
