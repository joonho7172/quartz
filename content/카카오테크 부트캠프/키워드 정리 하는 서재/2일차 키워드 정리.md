Thread의 start()와 run() 메서드의 차이점을 설명하고, run()을 직접 호출했을 때 왜 멀티스레드가 동작하지 않는지 JVM 관점에서 설명해주세요.

Thread 클래스를 상속받는 방식과 Runnable 인터페이스를 구현하는 방식의 차이점을 설명하고, 실무에서 Runnable이 선호되는 이유를 상속 제한과 실행 환경 관점에서 설명해주세요.

ExecutorService의 execute()와 submit() 메서드의 차이점을 예외 처리와 결과 반환 관점에서 설명하고, 각각 어떤 상황에서 사용해야 하는지 설명해주세요.

ThreadPoolExecutor의 corePoolSize, maximumPoolSize, keepAliveTime의 관계를 설명하고, 작업이 제출되었을 때 스레드가 생성되는 조건과 제거되는 시점을 단계별로 설명해주세요.

Thread Pool을 사용하지 않고 매번 new Thread()로 스레드를 생성할 때 발생할 수 있는 문제점을 시스템 자원, 성능, 운영 관점에서 각각 설명해주세요.

멀티스레드 환경에서 발생하는 Race Condition이 무엇인지 설명하고, synchronized를 사용한 해결 방법과 그 한계점을 성능 관점에서 설명해주세요.

Future와 CompletableFuture의 차이점을 비동기 처리와 조합 가능성 관점에서 설명하고, CompletableFuture가 콜백 지옥(Callback Hell)을 해결하는 방법을 설명해주세요.

Thread 내부에서 발생한 예외가 외부로 전파되지 않는 이유를 설명하고, UncaughtExceptionHandler를 사용한 예외 처리 방법과 실무에서의 활용 예시를 설명해주세요.

Executors.newFixedThreadPool()과 newCachedThreadPool()의 내부 동작 차이를 BlockingQueue 관점에서 설명하고, 각각 어떤 상황에서 OutOfMemoryError를 발생시킬 수 있는지 설명해주세요.

Thread.interrupt()가 스레드를 즉시 종료시키지 않는 이유를 설명하고, InterruptedException 처리와 isInterrupted() 플래그 확인이 필요한 이유를 설명해주세요.

Thread Pool의 거부 정책을 설명하고, 각각 어떤 상황에서 사용하는 것이 적절한지 실무 예시를 들어 설명해주세요.

Thread-safe하지 않은 컬렉션을 멀티스레드 환경에서 사용했을 때 발생할 수 있는 ConcurrentModificationException의 원인과 해결 방법을 설명해주세요.

데드락이 발생하는 4가지 필요조건을 설명하고, 각 조건을 깨뜨려 데드락을 방지하는 방법을 Java 코드 예시와 함께 설명해주세요.

Thread Local이 무엇이고, 멀티스레드 환경에서 어떤 문제를 해결하는지 설명한 후, Thread Pool과 함께 사용할 때 주의해야 할 메모리 누수 문제를 설명해주세요.
