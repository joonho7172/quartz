Reflection API가 무엇이고, 컴파일 타임이 아닌 런타임에 클래스 정보를 조회해야 하는 상황을 2가지 예시로 설명해주세요.

람다식이 익명 내부 클래스와 비교했을 때 어떤 장점이 있는지 설명하고, 함수형 인터페이스의 조건을 설명해주세요.

Optional의 of()와 ofNullable()의 차이점을 설명하고, 각각 언제 사용해야 하는지 예시를 들어 설명해주세요.

Optional의 orElse()와 orElseGet()의 차이점을 성능 관점에서 설명해주세요.

메서드 레퍼런스(::)가 무엇이고, 람다식을 메서드 레퍼런스로 변환할 수 있는 4가지 케이스를 설명해주세요.

Reflection을 사용한 동적 프록시(Dynamic Proxy)의 동작 원리를 설명하고, Spring AOP에서 어떻게 활용되는지 설명해주세요.

Reflection 사용 시 발생하는 성능 오버헤드의 원인과 이를 최소화하는 방법을 설명해주세요.

Optional을 필드, 메서드 매개변수, 컬렉션의 요소로 사용하면 안 되는 이유를 설명하고, Optional의 올바른 사용 패턴을 제시해주세요.

ClassLoader의 계층 구조와 동작 원리를 설명하고, 사용자 정의 ClassLoader가 필요한 상황을 예시로 설명해주세요.

람다식이 내부적으로 invokedynamic 바이트코드 명령어를 사용하는 이유와 이것이 익명 내부 클래스 방식보다 성능상 유리한 이유를 설명해주세요.

Optional의 flatMap()이 필요한 이유를 중첩된 Optional 처리 관점에서 설명하고, 실제 사용 예시를 제시해주세요.

Reflection을 통해 private 생성자를 가진 싱글톤 패턴을 깨뜨릴 수 있는 방법과 이를 방지하기 위한 대책을 설명해주세요.
