# **배경 (Background)**

- 프로젝트 목표 (objective): 더 안전하고 빠르게 사용자를 인증하고, 역할을 사용자와 관리자로 분리하여 각각 역할에 맞는 작업을 수행 할 수 있게 함.
	- 핵심 결과 1 : 일반 사용자는 관리자 권한으로 변경이 절대 안되게 함.
	- 핵심 결과 2 : 로그인 방법이 kakao 로그인 밖에 없는데 속도를 더 올리고자 함.
- 문제 정의 (Problem):
	- 현재 유저에서 관리자 api를 알고 넘어가려 하는 유저가 있음.
	- 카카오 로그인이 약간 느리다는 사용자가 있음.
- 가설 (Hypothesis) : 관리자 권한을 나타내는 DB의 admin, user 컬럼을 좀 더 명확하게 보안처리 해야겠음. 권한을 담는 토큰을 더 보안 처리.
