### N+1 조회 제거

방 참여자와 메시지 작성자 정보를 하나씩 조회하지 않고 ID 목록을 모아 한 번에 조회하도록 변경했습니다.

기존:

```
메시지 30개
→ 작성자 조회 30번
```

개선:

```
메시지 30개
→ 작성자 ID 수집
→ 사용자 일괄 조회 1번
```

방 입장에서도 참여자마다 사용자를 조회하지 않고 일괄 조회하도록 변경했습니다.
기존에는 참여자마다 캐시를 만들고 캐시를 저장해 응답에 사용했는데 이제 모든 사용자마다 별도 캐시를 하게 하여, 모든 사용자가 하나의 캐시를 공유하게 함.

원래는 사용자마자 MongoDB 조회 쿼리 반복, 이제는 redis 캐시가 만료되었을 때 1회만 실행해서 전부 가져옴.



효과:

- MongoDB round trip 감소
- 방 입장 및 메시지 목록 조회 지연 감소
- 동시 접속자 증가 시 DB 커넥션 경쟁 완화

### 방 입장·퇴장 처리 개선

- `Room`을 다시 조회하지 않고 갱신 결과를 재사용
- 참여자 목록을 batch 조회
- 중복 사용자 조회 제거
- 방 상세 응답 생성 과정의 반복 조회 제거
